## 2. Основной сценарий

1. Пользователь открывает приложение и входит по e-mail: вводит адрес, получает ссылку для входа (magic-link).
2. Вставляет учебный текст (до 10 000 знаков) или загружает файл — .txt, .docx, .pdf, изображение (OCR).
3. Нажимает «Упростить».
4. Сервер отправляет текст в GigaChat-2 с промптом, который требует сохранить факты, имена, числа, даты и структуру, но переписать текст простым языком.
5. Пользователь получает готовый текст и может скопировать его.
6. В интерфейсе видно, сколько запросов осталось на сегодня (лимит — 3 в сутки).

## 4. Ограничения

- **Только русский язык** — промпт и проверки рассчитаны на русские учебные тексты.
- **Лимит 3 запроса в сутки** на пользователя (настраивается через `DAILY_LIMIT`).
- **Максимум 10 000 знаков** на один текст.
- **Вход по magic-link**: без настроенного SMTP ссылка для входа пишется в логи сервера, а не приходит на почту.
- **Бесплатный хостинг засыпает** после ~15 минут простоя; первый запрос после сна выполняется около минуты.
- **VK-бот работает только в личных сообщениях** сообщества (не в комментариях к записям); на бесплатном хостинге бот останавливается, когда сервис засыпает.
- Качество упрощения зависит от GigaChat: возможны стилистические неточности, хотя факты, имена и числа сохраняются по инструкции промпта.
- Файлы PDF/изображения распознаются OCR — качество зависит от чёткости скана.
