# Дизайн-спецификация: «Текст по-человечески»

> Документ определяет визуальный язык, дизайн-токены, компоненты и состояния
> интерфейса. Источник функциональных требований — `tech_spec.md`;
> технический контекст — `ai_prompt.md`. Реализация: React + Tailwind CSS.
> Стиль: современный, минималистичный, «воздушный».

---

## 1. Принципы дизайна

1. **Крупные заметные кнопки** — зона нажатия ≥ 48px, высокий контраст.
2. **Читаемый текст** — базовый размер 16px, интерлиньяж 1.6–1.7.
3. **Единая сетка отступов** — все отступы кратны 8px (см. токены).
4. **Разделённые блоки** — карточки с фоном/тенью, никаких «каш» из элементов.
5. **Свободное пространство** — щедрые поля, ничего лишнего.
6. **Ограниченная палитра** — 3 основных цвета + нейтральные служебные.
7. **Максимум 2 шрифта** — один для заголовков/акцентов, один для текста.
8. **Тишина в интерфейсе** — никаких декораций вне контекста; иллюстрации
   только там, где они объясняют или утешают (пустые состояния, ошибки).

---

## 2. Палитра (3 основных цвета)

Палитра ограничена: один акцент, один позитив, один негатив. Остальное —
нейтральная шкала серых для фона, текста и границ.

| Токен | HEX | Роль |
|-------|-----|------|
| `--primary` | `#2F5BEA` | Акцент: кнопки, активные вкладки, ссылки, фокус |
| `--success` | `#1F9D6B` | Успех: готовый результат, «скопировано», остаток лимита |
| `--danger` | `#D64545` | Ошибка: лимит исчерпан, отказ контента, валидация |

Нейтральная шкала (служебная, не считается «цветом»):

| Токен | HEX | Роль |
|-------|-----|------|
| `--bg` | `#F7F8FB` | Фон страницы |
| `--surface` | `#FFFFFF` | Фон карточек/блоков |
| `--border` | `#E3E6ED` | Границы, разделители |
| `--text` | `#1A1D24` | Основной текст |
| `--text-muted` | `#6B7280` | Вторичный текст, подсказки, счётчики |
| `--primary-soft` | `#EAEFFF` | Подложка активной вкладки / hover-фон |
| `--success-soft` | `#E4F4EC` | Подложка блока результата |
| `--danger-soft` | `#FBEAEA` | Подложка блока ошибки |

**Тон (dark mode):** опционально, не в MVP. Если включается — `--bg #12141A`,
`--surface #1B1E26`, `--border #2A2E38`, `--text #F2F4F8`, акценты те же.

### Правила применения цвета
- Акцент (`--primary`) — единственный «шумный» элемент в поле зрения.
- `--success` и `--danger` появляются только в состояниях, никогда в декоре.
- Контраст текст/фон ≥ 4.5:1 (проверить `--text-muted` на `--bg` — ок).
- Не смешивать более одного акцентного цвета в одном блоке.

## 3. Типографика (2 шрифта)

| Роль | Шрифт | Fallback |
|------|-------|----------|
| Заголовки + UI-акценты (кнопки, вкладки) | **Inter** (600/700) | system-ui |
| Основной текст + результат | **Source Serif 4** (400/450) | Georgia, serif |

Логика: Inter структурирует интерфейс, Serif делает читаемым длинный
учебный текст результата — визуально отделяет «исходник» от «по-человечески».

Подключение (один запрос, self-host в MVP):
```html
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&family=Source+Serif+4:opsz,wght@8..60,400;8..60,600&display=swap" rel="stylesheet">
```

### Шкала размеров (Type scale, множитель ~1.25)

| Токен | Размер / Line-height | Вес | Где |
|-------|----------------------|-----|-----|
| `--fs-h1` | 32 / 40 | Inter 700 | Заголовок страницы |
| `--fs-h2` | 24 / 32 | Inter 600 | Заголовки блоков |
| `--fs-h3` | 18 / 26 | Inter 600 | Метки вкладок, подзаголовки |
| `--fs-body` | 16 / 26 (1.625) | Serif 400 | Текст ввода/результата |
| `--fs-ui` | 15 / 20 | Inter 500 | Подписи кнопок, формы |
| `--fs-caption` | 13 / 18 | Inter 400 | Счётчики, подсказки, хинты |

### Интервалы строк в контенте
- Textarea и результат: `line-height: 1.7`, `letter-spacing: 0`.
- Абзацы результата: отбивка `margin-bottom: 1em`.
- Списки: `padding-left: 1.25em`, `gap` между пунктами `0.4em`.
- Заголовки внутри результата (если OCR/MD их сохраняет): Serif 600, отступ
  сверху `1.5em`, снизу `0.5em`.

### Tailwind-маппинг
```ts
fontFamily: {
  sans: ['Inter', 'system-ui', 'sans-serif'],
  serif: ['"Source Serif 4"', 'Georgia', 'serif'],
}
```

## 4. Отступы, сетка, радиусы

Единая 8px-шкала. Ничего не выходит за неё.

| Токен | Значение | Применение |
|-------|----------|-----------|
| `--space-1` | 8px | внутренний gap меток |
| `--space-2` | 16px | отступы внутри карточки |
| `--space-3` | 24px | между связанными блоками |
| `--space-4` | 32px | между крупными секциями |
| `--space-5` | 48px | поля контейнера на desktop |
| `--space-6` | 64px | верх/низ страницы на desktop |

```ts
// Tailwind spacing уже кратен 4px — используем 4/6/8/12 (24/32/48px) напрямую.
```

**Радиусы:**
| Токен | Значение | Где |
|-------|----------|-----|
| `--radius-card` | 16px | карточки, блоки результата |
| `--radius-btn` | 12px | кнопки, поля ввода |
| `--radius-pill` | 999px | бейдж лимита, вкладки |

**Тени (мягкие, почти невидимые):**
- `--shadow-card`: `0 1px 3px rgba(26,29,36,.06), 0 8px 24px rgba(26,29,36,.06)`
- `--shadow-focus`: `0 0 0 3px rgba(47,91,234,.25)` (фокус-кольцо)

**Ширина контейнера:** `max-width: 720px`, центрирован. На mobile — `100%`
с полями `16px`. Одна колонка всегда (чистая читательская метрика).

## 5. Компоненты

### 5.1. Кнопка primary («Упростить», «Войти»)
- Фон `--primary`, текст белый, Inter 600, 15px.
- Высота 52px (mobile 48px), `padding: 0 28px`, радиус 12px.
- Hover: `filter brightness(.94)`. Active: `transform translateY(1px)`.
- Focus: `--shadow-focus`. Disabled: фон `#C4CCE8`, курсор not-allowed.
- Ширина: на mobile `100%`, на desktop `auto`.

### 5.2. Кнопка secondary / ghost
- Ghost: прозрачный фон, текст `--primary`, Inter 600.
- Outline: `1px solid --border`, текст `--text`, hover-фон `--bg`.
- Высота 44px. Для «Копировать», «Скачать .txt», «Вернуться к вводу».

### 5.3. Поле email (input)
- Высота 52px, радиус 12px, фон `--surface`, граница `--border`.
- Focus: граница `--primary` + `--shadow-focus`.
- Ошибка валидации: граница `--danger`, под полем текст `--fs-caption --danger`.

### 5.4. Textarea (ввод текста)
- min-height 200px (mobile 150px), Serif 16px/1.7.
- Счётчик знаков — внизу справа, `--fs-caption --text-muted`; при >9500
  цвет `--danger`.
- Граница/фокус как у input.

### 5.5. Вкладки ввода («Вставить текст» / «Загрузить файл» / «Загрузить фото»)
- Сегмент-контрол: пилюля-контейнер `--bg`, радиус 999px, padding 4px.
- Активная вкладка: фон `--surface` (или `--primary-soft`), текст `--primary`,
  Inter 600, тень `--shadow-card`.
- Неактивная: текст `--text-muted`.
- Mobile: если 3 метки не влезают — горизонтальный скролл без переноса.

### 5.6. Radio «Уровень простоты»
- Две карточки-опции рядом (mobile — столбиком).
- Карточка: `--surface`, граница `--border`, радиус 12px, padding 16px.
- Выбранная: граница `--primary` 2px + точка-маркер. Подпись Inter 600 +
  вторичный текст `--fs-caption --text-muted` с пояснением уровня.

### 5.7. Drop-zone (файл / фото)
- Пунктирная граница `--border` 2px, радиус 16px, padding 32px, фон `--bg`.
- Иконка + текст «Перетащите файл сюда или выберите» (ссылка `--primary`).
- Hover/drag-over: граница `--primary`, фон `--primary-soft`.
- После загрузки: имя файла + иконка + «Заменить» (ghost).
- Фото-зона: доп. кнопка «Сделать фото» (`capture="environment"`).

### 5.8. Бейдж лимита
- Пилюля `--radius-pill`, `--fs-caption`, Inter 500.
- Обычный: фон `--surface`, граница `--border`, текст `--text-muted`.
- Мало осталось (1): текст `--danger`. Исчерпан: фон `--danger-soft`,
  текст `--danger`.

### 5.9. Спиннер / лоадер
- Кольцевой SVG-спиннер 32px, цвет `--primary`, текст рядом «Обрабатываем
  текст…» (Inter 500 `--text-muted`).
- Опционально скелетон блока результата (серые полосы shimmer).
- Таймаут 30с → ghost-кнопка «Повторить».

### 5.10. Toast
- Сверху по центру, `--surface`, `--shadow-card`, радиус 12px, иконка статуса.
- Успех `--success`, ошибка `--danger`. Автоскрытие 3с.

### 5.11. Блок результата
- Карточка `--surface`, радиус `--radius-card`, `--shadow-card`, padding 24px.
- Фон-подложка секции `--success-soft` (мягко сигнализирует «готово»).
- Текст Serif 16px/1.7. Заголовок блока «Понятным языком» Inter 600 `--h3`.
- Кнопки «Копировать», «Скачать .txt» — ghost, справа сверху блока.

## 6. Экраны и состояния

Соответствие 7 состояниям из ТЗ (раздел 7).

### 6.1. Экран авторизации (состояние «Авторизация»)
Макет (1 колонка, вертикально, по центру):
1. Логотип + название «Текст по-человечески» (`--h1`).
2. Подзаголовок: «Понятно о сложном — без потери фактов» (`--body --text-muted`).
3. Иллюстрация (см. §7): спокойная сцена чтения.
4. Поле email + кнопка «Войти» (primary, 100% width).
5. Хинт `--fs-caption`: «Мы отправим ссылку для входа на почту».
- После отправки: сообщение-подтверждение (success-стиль) «Проверьте почту».
- Mobile: full-width, поля 16px.

### 6.2. Главный экран
Шапка: логотип слева, бейдж лимита «Осталось попыток: 2/3» справа.

Порядок блоков (сверху вниз, `--space-3` между ними):
1. **Уровень простоты** — radio-карточки (§5.6).
2. **Ввод** — вкладки + содержимое активной (§5.5, §5.4, §5.7).
3. **Кнопка «Упростить»** — primary, под блоком ввода.
4. **Результат** — §5.11 (появляется только в состоянии «Результат готов»).

Состояния главного:
- **Главная (пусто):** результат скрыт, кнопка disabled (textarea пуста).
- **Главная (текст введён):** кнопка активна.
- **Обработка:** кнопка → disabled со спиннером, под ней блок-лоадер (§5.9).
- **Результат готов:** блок результата, скролл к нему, toast-подсказка не нужна.
- **Лимит исчерпан:** кнопка disabled, вместо результата — экран-заглушка (§6.3).
- **Ошибка контента:** вместо результата — экран отказа (§6.3).

### 6.3. Экраны-заглушки (ошибки/лимит)
Центрированная карточка с иллюстрацией (§7), заголовком и текстом:
- **Лимит исчерпан:**
  - Иконка/иллюстрация «часы/отдых».
  - H2: «На сегодня всё».
  - Текст: «Вы использовали 3 попытки. Новые появятся завтра».
  - Ghost-кнопка «Понятно».
- **Ошибка контента:**
  - Иллюстрация «щит/стоп» (без агрессии).
  - H2: «Этот текст не получится упростить».
  - Текст: «Попробуйте другой фрагмент — например, из учебника или статьи».
  - Ghost-кнопка «Вернуться к вводу» (скролл к форме).

## 7. Иллюстрации (2D-вектор)

Стиль: плоские векторы (flat / line), тонкие контуры, закруглённые формы,
палитра строго из §2 (в основном `--primary` + `--primary-soft` + нейтральные).
Никаких фотографических или 3D-элементов. Много воздуха, один объект-герой.

**Бесплатные источники (лицензия для продакшена):**
- **unDraw** — https://undraw.co — монохромные SVG, цвет меняется в 1 клик
  (подставить `#2F5BEA`). Готовые сцены: `Undraw Reading`, `Undraw Online
  Reading`, `Undraw Documents`, `Undraw No Data`, `Undraw Timer`,
  `Undraw Shield`, `Undraw Email confirmation`.
- **SVGRepo** — https://www.svgrepo.com — фильтр «CC0 / license-free», поиск
  «reading flat», «document upload», «ocr scan».
- **Heroicons / Lucide** — https://lucide.dev — иконки UI (upload, file-text,
  image, copy, download, alert-triangle, clock, check-circle). Stroke 1.75px.
- **Storyset (Freepik)** — https://storyset.com — сцены «education/reading»,
  редактируются по цвету (требует атрибуцию на free-тарифе — учесть).

**Где использовать:**
| Место | Сцена |
|-------|-------|
| Экран логина | человек читает / открытая книга |
| Пустой результат | документ с «магической» трансформацией в чистый лист |
| Лимит исчерпан | часы / отдых |
| Ошибка контента | щит / мягкий «стоп-жест» |
| Drop-zone файла | иконка Lucide `file-up` (не сцена) |
| Drop-zone фото | иконка Lucide `camera` |

Правила: иллюстрация ≤ 240px по ширине, `margin: 0 auto`, alt-текст обязателен,
не дублирует смысл заголовка, а усиливает тон.

## 8. Иконки

Библиотека **Lucide** (уже в стеке промпта через `lucide-react`).
Размер 20–24px, `stroke-width: 1.75`, цвет наследуется от текста блока.
Не использовать emoji в UI (⚠️ из §5.3 ТЗ заменить на `alert-triangle`).

## 9. Адаптивность

| Breakpoint | Ширина | Поведение |
|-----------|--------|-----------|
| Mobile | <768px | 1 колонка, поля 16px, кнопки 100%, `--space-2/3` |
| Tablet | 768–1024px | 1 колонка, контейнер 720px, поля 24px |
| Desktop | >1024px | 1 колонка 720px, `--space-4/5`, максимум воздуха |

Правила:
- Вкладки, radio-карточки, textarea и результат **всегда столбиком** (ТЗ §9).
- Кнопки mobile — на всю ширину, min-height 48px (зона касания).
- Фото-зона mobile — явная кнопка камеры с `capture="environment"`.
- Счётчик знаков не должен перекрывать текст: резервировать нижнюю строку.
- Горизонтального скролла нет нигде (тест 375 / 768 / 1440).

## 10. Доступность (a11y)

- Контраст текста ≥ 4.5:1, крупных ≥ 3:1 (проверено для палитры §2).
- Focus-кольцо `--shadow-focus` на всех интерактивных элементах, не скрывать.
- Порядок Tab = визуальный порядок; radio-группа и вкладки — стрелки ←/→.
- Все поля имеют `<label>` (или `aria-label`); ошибки через `aria-live="polite"`.
- Спиннер: `role="status"` + `aria-busy` на области обработки.
- Иллюстрации декоративные → `aria-hidden`; содержательные → осмысленный `alt`.
- Управление не зависит только от цвета (лимит/ошибка дублируются текстом).
- `prefers-reduced-motion: reduce` → убрать shimmer/translate, оставить статичный индикатор.
- Touch target ≥ 44px.

---

## 11. Motion

Минимальный, служебный. Длительность 150–200ms, easing `ease-out`.
- Появление результата: fade + translateY(8px→0), 200ms.
- Hover кнопок: без движения, только цвет (кроме active translateY(1px)).
- Спиннер: непрерывное вращение (или статичный при reduced-motion).
- Никаких параллакс, пружин, лишних анимаций.
